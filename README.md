# LUMINA — Emotional Wellness Sanctuary
> *"You don't have to be happy to be worthy of peace."*

Developed under **RaaOS Studio**, **LUMINA** is a privacy-first, local-first emotional wellness web sanctuary designed to help individuals navigate stress, understand emotional patterns, and build resilience without clinical judgment.

## Core Pillars
- **2D Emotional Compass:** High-nuance mood & somatic mapping without toxic positivity.
- **AI Soul Companion:** Adaptive modes (*Listener, Grounder, Guide, Boundary Coach*) tailored to real-time emotional capacity.
- **Calm DNA:** Local pattern recognition that uncovers personal emotional triggers and restorative rituals.
- **Procedural Web Audio Sanctuary:** Real-time synthesized ambient rain and harmonic grounding tones.
- **Starlight Release & Future-Self Letters:** Cathartic particle dissolution and time-locked reflections.

## Architecture & Ethics
- **Framework:** Next.js (App Router), React, TypeScript, Tailwind CSS
- **Privacy-First Storage:** 100% Client-Side IndexedDB & LocalStorage (Zero cloud emotional data harvesting)
- **Audio Engine:** Native Web Audio API procedural synthesis
- **Ethical Guardrails:** Non-diagnostic by design with integrated crisis-support awareness
